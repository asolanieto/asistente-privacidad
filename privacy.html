Política de privacidad

Asistente personal · Última actualización: 22 de noviembre de 2026

Quién es el responsable

Asistente personal es una aplicación de uso personal, operada por su propio desarrollador en un servidor doméstico. El desarrollador es también su único usuario. Contacto: incidencias en GitHub.

Qué datos trata

  • Mensajes de Telegram (texto y notas de voz) que el usuario envía al bot, para guardarlos como notas, tareas o recordatorios. Las notas de voz se transcriben en el propio servidor y el audio se elimina después.
  • Google Tasks: el nombre de las listas y de las tareas, para crear tareas, moverlas entre listas y consultar las pendientes.
  • Google Calendar: los eventos del día, en modo solo lectura, para componer el resumen matinal.

Cómo los usa

Únicamente para ofrecer al usuario las funciones descritas. No se usan para publicidad, ni para perfilar, ni para entrenar modelos de inteligencia artificial de terceros. El procesamiento de lenguaje se hace con modelos que se ejecutan en el propio servidor, sin enviar el contenido a servicios externos de IA.

Con quién se comparten

Con nadie. Los datos obtenidos de Google no se venden, no se ceden y no se transfieren a terceros. Un humano solo los ve si el propio usuario los consulta. El uso que la aplicación hace de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Dónde y cuánto tiempo se guardan

Las notas y recordatorios se guardan en una base de datos del servidor doméstico, con copias de seguridad cifradas por el acceso restringido al propio servidor. El token de acceso a Google se guarda en un fichero del servidor con permisos restringidos. Las notas se conservan hasta que el usuario las borra. Los datos de Google Tasks y Calendar no se copian: se consultan cuando hacen falta.

Tus derechos y cómo revocar el acceso

Puedes borrar tus notas en cualquier momento y retirar el acceso de la aplicación a tu cuenta de Google desde myaccount.google.com/permissions. Al revocarlo, la aplicación deja de poder leer o modificar tus datos de Google.

Cambios

Si esta política cambia, se actualizará esta página con la nueva fecha.
